## Summary

Shipping `/attention` as Concept 05 in Series I — On language models. An
interactive attention-matrix heatmap (hover a token, see what it attends to)
plus a head selector and a scaled dot-product equation card make the
transformer's core mechanism legible. All attention weights are precomputed
and shipped as static JSON — no runtime inference. Awaiting maintainer manual
review.

## Environment note

Work is performed in an isolated git worktree (`/home/ubuntu/att-wt`) on
branch `plan/attention-mechanism` because the shared `/workspace` checkout is
used concurrently by other ship-article agents (branches: espresso-machine,
mesh-networks, adaptive-music, testing-suite). The worktree gives this run an
independent HEAD/index so concurrent `git checkout` operations cannot clobber
it. node_modules is symlinked from `/workspace`.
